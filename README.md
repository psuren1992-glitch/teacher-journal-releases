# Журнал учителя для Краснодарского края

Неофициальное тестовое Android-приложение для работы с электронным журналом с телефона. Нужны действующий доступ к журналу и интернет. Это не приложение Госуслуг и не официальный продукт оператора журнала.

APK рассчитан на Android 7 и новее, ARM64 и ARMv7. Совместимость со всеми моделями не гарантируется. Обновление устанавливайте поверх предыдущей версии, не удаляя приложение.

## Чем удобно

- Класс, предмет, занятие и ученики открываются в мобильных списках.
- Есть выбор обычного журнала, надомного обучения и доступных дополнительных журналов.
- Во внеурочке: группы, занятия, разрешённые отметки, комментарии, постановка и снятие Н, файлы и фотографии в «Комментарий / ДЗ».
- В роли «Учитель» список предметов содержит только свои предметы; в роли «Завуч» сохранён полный список.
- Оценки, тема урока и выдача ДЗ доступны на экране занятия.
- Есть выбор темы из КТП и перенос текста темы в домашнее задание.
- К ДЗ можно прикрепить документ, фото из галереи или снимок камеры; текст можно продиктовать при наличии службы распознавания.
- Перекличка открывает список с поиском и флажками отсутствующих на конкретном занятии.
- Домик «На дому» отмечает надомное обучение по данным журнала для выбранного занятия или дня.
- Под ФИО показывается доступная средняя с ненавязчивым цветом; список можно сортировать по алфавиту или от низкой средней.
- В меню «Школа и вход» под версией можно выбрать оформление: «Классика», «Школьная» или «Тёмная». Выбор запоминается на телефоне.
- К оценке можно добавить текстовый комментарий, изменить или очистить его.
- Для сохранения приложение запрашивает подтверждение и проверяет результат в журнале.

## Что изменилось в 0.3.14

- Выбор типа журнала берётся из доступных разделов текущего аккаунта. Для надомного обучения предусмотрены отдельные списки и привычные редакторы.
- Во внеурочке отметки выбираются из шкалы конкретного журнала, например «зачет». Можно добавить комментарий и очистить доступную ячейку.
- «Перекличка» позволяет поставить Н или снять ошибочную Н на выбранном занятии. Уже имеющиеся оценки не перезаписываются.
- В «Комментарий / ДЗ» доступны файлы, фото из галереи, камера и диктовка. Старые вложения сохраняются; убрать выбранный файл из занятия можно отдельно, с подтверждением.
- Каждая отправка проверяется повторным чтением. При неизвестном результате автоматической повторной записи нет.

Это тестовый выпуск: 176 автоматических тестов и проверка TypeScript пройдены. Формы и код официального клиента изучены только в режиме чтения; реальные записи учеников и хранилище ради проверки не менялись. Проверка нового функционала на телефоне и фактической серверной записи ещё предстоит.

При неоднозначной связи нескольких занятий одной даты с колонками, неизвестном формате или отсутствии прав запись отключается. Итоговые отметки внеурочки не реализованы. Средняя для внеурочки не рассчитывается по пятибалльной шкале.

## Сохранено из 0.3.12

- Выбор класса в посещаемости оформлен отдельной кнопкой «Выбрать класс» со стрелкой. Такая кнопка также доступна на экранах предметов, занятий и учеников.
- Название класса или предмета выделено более крупным полужирным текстом. ФИО показано отдельной строкой в скобках, меньшим обычным шрифтом и другим цветом. Оформление работает в трёх темах.
- Исправлена загрузка предметников при недоступном справочнике сотрудников: приложение также читает подписи учителей в заголовках соответствующих групп официального журнала. ФИО появляются по мере загрузки, без ожидания всего списка.
- В выборе классов посещаемости сохранены дополнительные подписи классных руководителей.

Справочник позволяет показать полное ФИО; если журнал передал только фамилию и инициалы, показывается эта подпись. При недоступных или неоднозначных сведениях имя не выдумывается. Получение этих данных и новый интерфейс ещё нужно проверить на телефоне с действующей учётной записью.

Выбор доступных классов завуча и удаление пилота MAX из 0.3.11 сохранены. Права аккаунта не расширены.

## Возможности и ограничения

Исправлена причина появления «Средняя недоступна», когда сайт заполняет среднюю после загрузки. Приложение использует готовое значение из ответа либо рассчитывает поддержанную пятибалльную схему по правилам сохранённой версии сайта с учётом весов и округления. Для неизвестных схем и неоднозначных данных остаётся «Средняя недоступна», а не ноль. Совпадение с текущим сайтом и отображение на телефоне ещё предстоит проверить. Цвет не является рекомендацией итоговой оценки.

Три темы меняют мобильные экраны приложения; официальные страницы журнала, Госуслуг и содержимое Яндекс Форм сохраняют своё оформление. Смена темы не перезапускает вход.

**Дневная запись посещаемости в роли «Учитель» временно отключена для всех классов, в том числе у классных руководителей.** Пока приложение не умеет надёжно подтверждать назначенный класс, раздел доступен только для просмотра. Перекличка отдельного занятия работает по правам журнала. У завуча дневные операции сохранены.

Сохранено снятие выбранных дневных Н с подтверждением. Перекличка и комментарии прошли автоматические тесты, но ещё требуют проверки на устройстве и живом журнале. Отображение комментариев у ученика и родителя отдельно не проверено. Прикрепление фото к комментарию не поддержано. Реальные записи ради тестирования не создавайте.

Нет офлайн-отправки, гарантии длительной сессии и входа по PIN. При истечении сессии нужен повторный вход. Сообщение об ошибке отправляется через кнопку с восклицательным знаком в приложении.
