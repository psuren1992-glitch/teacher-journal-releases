# Журнал учителя для Краснодарского края

Неофициальное тестовое Android-приложение для учителей и завучей, у которых уже есть доступ к электронному журналу. Оценки, темы, домашние задания и перекличка с телефона, без необходимости искать компьютер перед уроком.

**Текущая версия: 0.3.19 · 19 октября 2026 года.**

[Скачать APK 0.3.19](https://github.com/psuren1992-glitch/teacher-journal-releases/releases/download/v0.3.19/teacher-journal-0.3.19-test-universal-arm.apk) · [Инструкция для пользователя](USER_GUIDE.md) · [Описание выпуска](https://github.com/psuren1992-glitch/teacher-journal-releases/releases/tag/v0.3.19)

Это не приложение Госуслуг и не официальный продукт оператора журнала. Для работы нужны интернет, действующая учётная запись и разрешённые ей права.

## Чем удобно

- **Весь класс и занятия в одной таблице.** Ученики по строкам, занятия периода по столбцам; фамилии и даты закреплены. Есть поиск, сортировка, выбор группы и переход к дате.
- **Быстрые оценки прямо из ячейки.** Выберите оценку или «Н», при необходимости добавьте текстовый комментарий. Можно сохранить и перейти к следующему ученику без открытия отдельного окна на каждого.
- **Привычный экран занятия.** Во вкладке «Занятия» остаётся путь класс → предмет → урок → ученики. «Тема урока», «Выдать ДЗ» и «Перекличка» выделены отдельными кнопками.
- **Темы и ДЗ из КТП.** Можно выбрать готовую тему или задание; если в плане есть только тема, перенести её текст в ДЗ и дополнить.
- **Материалы прямо с телефона.** Документ, PDF, фото из галереи или снимок камеры можно прикрепить к ДЗ. Диктовка помогает набрать текст, если на телефоне доступна служба распознавания.
- **Перекличка конкретного занятия.** Поиск по списку и флажки отсутствующих, без необходимости заходить к каждому ученику отдельно.
- **Средняя оценка рядом с учеником.** Доступная средняя показана с ненавязчивым цветом; сортировка помогает увидеть учеников с низкой средней. Значок «На дому» отражает сведения журнала.
- **Разные типы журналов.** Обычные уроки, надомное обучение и доступная аккаунту внеурочка. Во внеурочке поддержаны разрешённые отметки, комментарии, постановка и снятие «Н», материалы в «Комментарий / ДЗ».
- **Три оформления.** «Классика», «Школьная» и «Тёмная» в меню «Школа и вход»; выбор сохраняется на телефоне.
- **Официальный журнал под рукой.** Можно открыть полный вид со всеми столбцами и вернуться кнопкой «Мобильный журнал».

В роли «Учитель» мобильный список предметов показывает свою нагрузку; в роли «Завуч» сохранён полный доступный список. Приложение не расширяет права аккаунта.

## Что исправлено в 0.3.19

- Если прежняя отправка сделана в другой роли, проверка теперь подсказывает, к какой роли вернуться. Недоступный исходный журнал не подменяется другим.
- При изменении темы внеурочки сохраняется исходное содержимое соседнего поля «Комментарий / ДЗ»: исправлена передача текста `false` вместо него.
- При ручной сверке видны тема, комментарий / ДЗ и вложения, а не только одно поле.
- Завершение сверки снимает только локальную блокировку, без повторной отправки и без автоматического изменения уже сохранённых данных.

Ранее записанный текст `false` автоматически не удаляется. Мобильная таблица и исправление доступности «Н» из предыдущих выпусков сохранены.

## Установка и обновление

1. Скачайте APK по ссылке выше на Android-телефон и откройте загруженный файл.
2. При необходимости разрешите установку только для браузера или файлового менеджера, которым открыли файл. Не отключайте защиту телефона; при предупреждении об угрозе остановитесь и сообщите разработчику.
3. Установите APK **поверх предыдущей версии**. Не удаляйте приложение и не очищайте данные: там могут храниться сведения о неподтверждённой отправке.
4. Для первого входа пройдите авторизацию на официальной странице Госуслуг. Никому не передавайте пароль и код.

Android 7 и новее, ARM64 и ARMv7. Поддержка всех моделей не гарантируется. Для iPhone этот файл не подходит; Expo Go и компьютер для установки не нужны.

## Если осталась блокировка

Нажмите **«Проверить прежнюю отправку»**. Если приложение просит исходную роль, выберите её в «Школа и вход» и повторите проверку. Сверьте занятие и показанные значения; завершайте ручную сверку только после проверки результата.

Эта процедура не отправляет запись повторно и не исправляет расхождения на сервере. После завершения вернитесь в нужную роль и заново откройте форму. Не очищайте данные приложения ради снятия ошибки.

## Сессия и сохранение

В меню «Школа и вход» есть экспериментальное **«Поддерживать вход»**, по умолчанию выключенное. При включении Android периодически читает журнал в фоне. Это не обход авторизации: срок сессии зависит от сервера и ограничений телефона, день или два без повторного входа не гарантируются. При необходимости снова используется официальный вход; PIN не реализован.

**Запись считается завершённой только после подтверждения результата приложением.** Выбор оценки, ввод текста или прикрепление файла сами по себе ничего не выдают ученикам. При неизвестном результате приложение предлагает проверку, а не автоматический повтор отправки. Офлайн-очереди и гарантированного сохранения черновиков пока нет.

## Важные ограничения

- Мобильные экраны поддерживают роли «Учитель» и «Завуч», не роль «Администратор».
- Дневная запись посещаемости в роли «Учитель» временно отключена, включая классных руководителей: пока приложение не может надёжно подтвердить назначенный класс, доступен просмотр. Перекличка отдельного занятия работает по правам журнала; у завуча дневные операции сохранены.
- Снятие «Н» и удаление оценки в обычном предметном редакторе не реализованы. Для исправления используйте официальный журнал или доступную дневную посещаемость. Во внеурочке действуют отдельные поддержанные операции.
- Фото к комментарию оценки не поддерживается. Вложения доступны в ДЗ и заметке занятия внеурочки.
- Средняя выводится только для поддержанных данных; неизвестные схемы не заменяются нулём. Цвет средней не является рекомендацией итоговой оценки.
- Не все специальные работы, итоговые отметки внеурочки и сложные варианты расписания поддержаны. Изменения официального сайта могут потребовать обновления приложения.
